# Nxt Trendz - E-Commerce Platform

A modern e-commerce application built with React that showcases cart features, user authentication, and product browsing capabilities.

## 🛍️ Application Overview

Nxt Trendz is a fully functional e-commerce platform that demonstrates:
- User authentication (Prime vs Non-Prime users)
- Product catalog with search and filtering
- Shopping cart management
- Order placement and tracking
- Responsive design for all devices

## 🔐 Login Details

### Prime User (Premium Features)
```text
Username: rahul
Password: rahul@2021
```
**Benefits:**
- Free shipping on all orders
- Exclusive deals and discounts
- Priority customer support

### Non-Prime User (Standard Features)
```text
Username: raja
Password: raja@2021
```
**Features:**
- Standard shipping rates apply
- Regular pricing
- Basic customer support

## 🚀 How the App Works

### 1. **Authentication Flow**
- Users can log in with the provided credentials
- System differentiates between Prime and Non-Prime users
- Session management maintains login state

### 2. **Product Browsing**
- Browse products by category
- Search functionality to find specific items
- Sort products by various criteria
- Filter results based on preferences

### 3. **Shopping Cart**
- Add products to cart with quantity selection
- View cart summary with pricing
- Update or remove cart items
- Apply promotional codes (for Prime users)

### 4. **Checkout Process**
- Review order details
- Select shipping options
- Enter payment information
- Confirm and place order

### 5. **Order Management**
- View order history
- Track order status
- Cancel orders (if applicable)

## ✨ Key Functionalities

### User Features
- **Authentication System**: Secure login with role-based access
- **Profile Management**: View and edit user details
- **Order History**: Track all past and current orders

### Product Features
- **Catalog Display**: Grid/list view of products
- **Advanced Search**: Search by name, category, or price
- **Product Details**: Detailed view with images and specifications
- **Wishlist**: Save favorite products for later

### Cart Features
- **Add to Cart**: Quick add with quantity selection
- **Cart Management**: Update quantities, remove items
- **Price Calculation**: Real-time price updates with taxes
- **Saved Carts**: Persist cart items across sessions

### Premium Features (Prime Users)
- **Free Shipping**: No shipping charges
- **Exclusive Discounts**: Special member pricing
- **Early Access**: New product previews
- **Priority Support**: Enhanced customer service
